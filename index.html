Revenue Monster Card Checkout Demo

Sandbox test page for the card checkout + 3DS challenge flow.
This page calls the Sandbox environment only.
Steps 1–3 require node server.js running locally (proxies + signs the requests). Step 4 works standalone — it calls Revenue Monster directly from the browser.

4-Step Flow

  1. Get Access Token — OAuth client credentials (Basic auth: Client ID + Client Secret, base64). Fills the Bearer Token field, used by steps 2–3.
  2. Create Order — creates the order under the selected Store ID. Fills the Order Checkout ID field, used by step 3.
  3. Get Checkout Code — selects the payment method (hardcoded to MASTERCARD_MY) for that order. Fills the Checkout Code field, used by step 4.
  4. Card Checkout — submits card details against the checkout code. On success, opens the 3DS challenge in the iframe below.
